Archived approval/WhatsApp implementation
=========================================

These files were part of the earlier Senior -> Client approval POC using secure
review links, FastAPI, Meta WhatsApp Cloud API, and n8n notifications.

They are intentionally NOT used by the current Excel-only app. They are retained
only so the work is not lost if approval automation is reintroduced later.

Do not move these modules back into the active project or enable their workflows
unless the approval architecture is intentionally restored and retested.
